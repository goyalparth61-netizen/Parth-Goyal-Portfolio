# Parth Goyal — Portfolio

A high-end interactive portfolio for **Parth Goyal**, focused on cybersecurity, full-stack development, AI, networking, and hands-on technical projects.

## Stack

- Next.js
- React
- TypeScript
- CSS
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Project structure

```text
app/
  globals.css
  layout.tsx
  page.tsx
```

## Portfolio direction

The site is designed as a dark, editorial cybersecurity portfolio with animated grid layers, terminal UI, project interactions, responsive layouts, and a future interactive Cyber Lab / AI assistant layer.

## Deployment

The project can be deployed to Vercel or any platform that supports Next.js.
